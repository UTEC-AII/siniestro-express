# Informe

Código fuente del informe del proyecto final y su versión compilada.

## Compilar

```bash
pdflatex -interaction=nonstopmode SiniestroExpress_Proyecto_Final.tex
pdflatex -interaction=nonstopmode SiniestroExpress_Proyecto_Final.tex
```

Dos pasadas: la primera genera el índice y las referencias, la segunda los resuelve.

| Archivo | Contenido |
